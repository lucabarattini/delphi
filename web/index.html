Delphi

The crowd is the oracle. Shall we trust the crowd?

In ancient Greece, Delphi was home to the Pythia, the oracle that everyone would travel to see.

In this little experiment, I want to make the controversial claim that Kalshi is today's new oracle.

This is because, if you think about it, people who bet on Kalshi have access to inputs that no deep learning model could have.

So I want to see whether Kalshi was right, for tonight's games or for any night of this season. And, if I think it might be right about tonight's game, I want to see where my bet would land if I put X dollars on it.

The agent uses four tools, all defined in scripts/tools.py.
